# design

## skill-eval-accuracy — スキルの精度検証を CI で回せるようにしたい
- meta: origin: llm / status: open / 起票: 2026-08-09
- 内容: スキルの出力品質を継続的に評価するため、CI 上で「評価データ」と「実行データ」を比較して精度を測る仕組みを整えたい。具体的には、正解データセットと実行結果の差分を自動採点し、結果を PR やログに残すフローを考えている。
- 根拠: 現在のリポジトリには、スキルの精度評価や CI ベースの回帰検証の仕組みがなく、[AGENTS.md](../../../../AGENTS.md) に課題管理の宣言はあるが、評価データの比較方法や実行基準の定義は存在しない。
- 提案（任意）: 1. 評価用データセットを `tests/evals/` などに置き、各ケースに「入力」「期待出力」「実行条件」を持たせる。2. CI で評価スクリプトを実行し、各ケースごとに実行結果を収集する。3. 実行結果を期待出力と比較し、完全一致・部分一致・差分の 3 種類でスコアを算出する。4. 結果を JSON/Markdown として保存し、PR コメントや GitHub Actions アーティファクトに投稿する。5. しきい値を設けて、スコア低下時に CI を fail させる。6. まずは小さなサンプルセットで導入し、後で複数スキル・複数モデルへの拡張を検討する。
